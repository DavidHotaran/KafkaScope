# KafkaScope

KafkaScope is an open-source, web-based admin console for Apache Kafka. It gives you a clear view into your cluster's topics — inspect messages, monitor throughput, and understand what's flowing through your data pipelines at a glance. Beyond visibility, KafkaScope lets you manage topics end-to-end: create and configure topics, produce messages, and consume/browse them directly from the browser — no CLI required.

Built for developers and ops teams who want a lightweight, self-hostable alternative to juggling kafka-console-producer and kafka-console-consumer scripts.
